Algorithms & Data Structures

Artifact overview

The original artifact was a Binary Search Tree from a lab. Instead of keeping the original bid-auction example I rebuilt the program around a pet registry idea where each record stores a pet's name, species, microchip number, and owner. r. The program uses a binary search tree to search for pets by microchip, merge sort to sort pets by microchip number, and binary search to find a pet in the sorted list. The main function runs a small demo that loads sample pets, prints the merge-sorted list, and shows both search methods in action..

Why I selected this artifact

It shows that I can take a basic lab assignment and turn it into something original that still meets course goals. The PetSearchTree class demonstrates my understanding of tree structure, recursive insertion, and tree-based search. The mergeSortPets and merge functions show that I understand divide-and-conquer sorting and how to combine sorted sublists. The binarySearchPet function shows that I can search efficiently on sorted data using index-based logic. I improved the artifact by moving away from the incomplete starter code and CSV bid data. I designed my own Pet struct, wrote my own pseudocode first, and then implemented everything in one clean file with no outside dependencies. That made the code easier to read and helped me focus on the algorithms instead of assignment scaffolding.

Reflection

I learned that planning with pseudocode before coding made the implementation much smoother, especially for merge sort and binary search. I also learned that the same real-world problem can be solved in more than one way. A BST and binary search both find a pet by microchip, but they work on different structures and have different requirements, like needing sorted data first for binary search. One challenge I faced was deciding how much of the original lab to keep. At first, I tried to adapt the old assignment file, but that felt cluttered and off-topic, so I restarted from zero with the pet theme, which was harder at the beginning but gave me a much better final result. Another challenge was making sure my merge sort logic matched my pseudocode closely, especially in the merge step when comparing the first items of each half. Testing with sample data and checking the sorted output helped me confirm that everything worked correctly. Overall, this project helped me feel more confident writing and explaining fundamental algorithms on my own.
